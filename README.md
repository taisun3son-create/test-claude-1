# test-claude-1

陽だまり家事サポート（愛知県瀬戸市のシニア世帯向け家事代行サービス）のウェブページ。

`index.html` の1ファイルで完結しています。ビルド不要で、そのままブラウザで開けます。
外部依存は Google Fonts（Shippori Mincho B1 / Zen Kaku Gothic New）のみで、
読み込みに失敗した場合も明朝・ゴシックのフォールバックで表示されます。

## 実装上の決めごと

利用者の多くが高齢者であることを前提に、次の点を守っています。

- **文字サイズは3段階（標準・大・特大）**。選択は `localStorage` に保存し、次回以降も維持します。
- **エラー表示の行はあらかじめ場所を確保**しています（`.err` の `min-height`）。
  入力を直した瞬間に下のボタンや同意欄が動くと押し間違いの原因になるためで、
  文言を1行に収める前提で長さを調整しています。
- **エラーは色だけで伝えない**。枠線の色に加えて、必ずテキストとアイコン、
  さらにフォーム冒頭のサマリー（`role="alert"`）でも伝えます。
- **タップ領域は44px以上**。同意チェックボックスは行全体を押せるようにしています。
- **ヘッダーの高さは実測して `--head-h` に反映**します。文字サイズを変えると
  ヘッダーの高さも変わるため、固定値だとアンカー移動時に見出しが隠れます。
- 1000px以下ではグローバルナビをドロワーに切り替えます（Escape・背景クリックで閉じ、
  フォーカストラップあり）。
- ヘッダーは2段構成です。1段目に社名・文字サイズ・電話、2段目にナビゲーションを
  置いています。1段に詰めると項目が入りきらず、意図しない位置で折り返すためです。

## 公開前に記入が必要な箇所

電話番号と所在地は実在の値を入れていません。次の箇所を差し替えてください。

- **電話番号**: ヘッダー、ヒーローのボタン、ドロワー、予約欄の telcard、
  モバイル下部バー、フッターの計6か所。いずれも「電話番号を記入」と表示されます。
  記入する際は、仮の見た目である `.btn--todo` / `.is-todo` を外し、
  `href="tel:..."` を付け直してください（ボタンは `.btn--tel` に戻します）。
- **所在地・郵便番号**: フッターの `<address>`。あわせて JSON-LD の
  `address` に `postalCode` と `streetAddress` を追加してください。
- **JSON-LD の `telephone`**: 番号が決まるまで、あえて項目ごと入れていません。
- **`canonical` と OGP の URL**: いまは `https://example.com/` のままです。
- **プライバシーポリシー / 特定商取引法に基づく表記**: リンク先の実体がまだありません。

## 内容についての注意

「お客様の声」の3件は仮の文章です。実際にいただいた声に差し替えてください。
損害賠償保険（1事故あたり最大1億円）の記載も、契約内容に合わせて確認が必要です。

承っていないサービス（お料理、通院・お出かけの付き添い、エアコンなどの分解洗浄、
身体介護）は、料金表の下に明記しています。提供範囲を変える場合はここも直してください。

## 検証

Playwright で確認済みの項目（デスクトップ1280px / モバイル390px）:
文字サイズの保存と復元、料金試算の計算結果、フォームのバリデーションと完了時の
フォーカス移動、ドロワーの開閉とキーボード操作、横スクロールの不発生、
特大文字時を含むアンカー移動でヘッダーが見出しを隠さないこと、
「ご予約」からの遷移、実在しない電話番号へのリンクが残っていないこと。

なお予約フォームは画面上の動作のみで、送信先はまだありません。
