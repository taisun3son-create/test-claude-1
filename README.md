# test-claude-1

陽だまり家事サポート（愛知県瀬戸市のシニア世帯向け家事代行サービス）のウェブページ。

`index.html` の1ファイルで完結しています。ビルド不要で、そのままブラウザで開けます。
外部依存は Google Fonts（Shippori Mincho B1 / Zen Kaku Gothic New）のみで、
読み込みに失敗した場合も明朝・ゴシックのフォールバックで表示されます。

## 実装上の決めごと

利用者の多くが高齢者であることを前提に、次の点を守っています。

- **文字サイズは3段階（標準・大・特大）**。選択は `localStorage` に保存し、次回以降も維持します。
- **エラー表示の行はあらかじめ場所を確保**しています（`.err` の `min-height`）。
  入力を直した瞬間に下のボタンや同意欄が動くと押し間違いの原因になるためで、
  文言を1行に収める前提で長さを調整しています。
- **エラーは色だけで伝えない**。枠線の色に加えて、必ずテキストとアイコン、
  さらにフォーム冒頭のサマリー（`role="alert"`）でも伝えます。
- **タップ領域は44px以上**。同意チェックボックスは行全体を押せるようにしています。
- **料金は全プランで単位をそろえています**。大きい数字は必ず「1時間あたり（税込）」で、
  その下に「2時間ぶんの料金 ＋ 交通費900円 ＝ 1回あたりの支払額」を式のまま出します。
  以前は「5,500円／2時間」と「2,750円／1時間」が混在し、交通費も注記だけにあったため、
  実際に払う金額が読み取れませんでした。
- **ヘッダーの高さは実測して `--head-h` に反映**します。文字サイズを変えると
  ヘッダーの高さも変わるため、固定値だとアンカー移動時に見出しが隠れます。
- **スクロール表示演出は `html.js` が付いているときだけ効かせます。** `<head>` の
  小さなスクリプトがこのクラスを付けるので、スクリプトが動かない環境では
  `.rv` は最初から見えたままになります。`.rv{opacity:0}` を無条件にかけると、
  スクリプトが1か所でも失敗した瞬間に本文がまるごと消えます。
- **スクリプトは機能ごとに `run()` で囲んで独立させています。** 1本につなげると、
  途中の例外でメニューも演出もまとめて止まります。
- **ヘッダーの社名と表紙の文字は、文字サイズ設定に追随させません**（`px`/`vw` 基準）。
  文字サイズは本文を読みやすくするための機能で、ここまで拡大すると
  狭い画面でヘッダーが崩れ、表紙の副題が画面幅を超えます。
- 表紙は `100svh` を使ってヘッダー分を引いた高さにしています。スマホの
  `100vh` はアドレスバーの分だけずれるためで、非対応環境向けに `vh` と
  固定値の段階的な指定を並べています。
- `-webkit-text-size-adjust` と `-webkit-backdrop-filter` を併記し、`inset` は
  `top/right/bottom/left` に展開しています（iOS Safari の対応状況のため）。
- 1000px以下ではグローバルナビをドロワーに切り替えます（Escape・背景クリックで閉じ、
  フォーカストラップあり）。
- ヘッダーは2段構成です。1段目に社名・文字サイズ・電話、2段目にナビゲーションを
  置いています。1段に詰めると項目が入りきらず、意図しない位置で折り返すためです。

## スマホでの長さ対策

縦に積み上がるため、対策前は iPhone 13 で約25画面ぶん（16,492px）ありました。
余白の圧縮に加えて、補助的な部分を折りたたむことで約11,600px（約14〜17画面）まで
縮めています。**パソコン表示には一切影響させていません**（`max-width:780px` の中だけ）。

畳んでいるのは次の4か所で、いずれも「もっと見る」ボタンで開けます。

| 対象 | 初期表示 | ボタン |
|---|---|---|
| 料金プラン | おためし・週1回の2枚 | 隔週・単発のプランを見る |
| かんたん試算 | 見出しのみ | 料金を試算してみる |
| お客様の声 | 1件 | ほかの声を読む（2件） |
| 予約フォームの任意項目 | 非表示 | くわしく伝える（任意） |

比較して選ぶ料金プランは、いちばん安いものと定番の2枚を残しています。
全部畳むと単価の比較ができなくなるためです。

畳む処理はスクリプトが担当します（`.more[aria-controls]` と対象の `id` を対応させる）。
スクリプトが動かない環境ではボタンが `hidden` のままで、中身は最初から全部表示されます。

そのほか、表紙に実写を入れた時点でヒーローの障子イラストは役割が重複するため、
スマホでは非表示にしています（500px以上を占めていました）。

## 表紙の写真

元画像は `24523121_l.jpg`（2500×1667、2.3MB）。これを 1600×1067・品質78 に圧縮し、
`:root` の CSS変数 `--cover-photo` にデータURIとして埋め込んでいます（埋め込み後 249KB、
`index.html` 全体で約332KB）。差し替えるときはこの1行だけを置き換えてください。

データURIにしているのは、`index.html` 単体をスマホに送っても写真が出るようにするためです。
別ファイル運用に変える場合は `url("images/cover.jpg")` でも動きます。

写真の位置は画面の形で変えています。横長の画面ではほぼ全体が入りますが、
縦長のスマホでは左右が切れるため、3人が収まるよう中央に置いています
（`background-position`）。

白文字が沈まないよう、写真の上に中央を濃くした二重の膜（`.cover__veil`）をかけています。
実際に描画したピクセルからコントラスト比を測り、背景の明るいほうから5%の部分で見ても
題字4.5:1以上・副題5.0:1以上（WCAG AA の基準は大きい文字3:1、通常4.5:1）を確認しています。

## 公開前に記入が必要な箇所

電話番号と所在地は実在の値を入れていません。次の箇所を差し替えてください。

- **電話番号**: ヘッダー、ヒーローのボタン、ドロワー、予約欄の telcard、
  モバイル下部バー、フッターの計6か所。いずれも「電話番号を記入」と表示されます。
  記入する際は、仮の見た目である `.btn--todo` / `.is-todo` を外し、
  `href="tel:..."` を付け直してください（ボタンは `.btn--tel` に戻します）。
- **所在地・郵便番号**: フッターの `<address>`。あわせて JSON-LD の
  `address` に `postalCode` と `streetAddress` を追加してください。
- **JSON-LD の `telephone`**: 番号が決まるまで、あえて項目ごと入れていません。
- **`canonical` と OGP の URL**: いまは `https://example.com/` のままです。
- **プライバシーポリシー / 特定商取引法に基づく表記**: リンク先の実体がまだありません。

## 内容についての注意

**おためしプランが割引になっていません。** 2時間5,500円は時間あたり2,750円で、
定期・週1回とまったく同じ単価です。交通費を加えた1回あたりの支払額も6,400円で一致します。
単価をそろえて表示したことで、この点が画面上ではっきり見えるようになりました。
初回を割安にする意図があるなら、金額の見直しが必要です。

「お客様の声」の3件は仮の文章です。実際にいただいた声に差し替えてください。
損害賠償保険（1事故あたり最大1億円）の記載も、契約内容に合わせて確認が必要です。

承っていないサービス（お料理、通院・お出かけの付き添い、エアコンなどの分解洗浄、
身体介護）は、料金表の下に明記しています。提供範囲を変える場合はここも直してください。

## 検証

Playwright で確認済みの項目（デスクトップ1280px / モバイル390px）:
文字サイズの保存と復元、料金試算の計算結果、フォームのバリデーションと完了時の
フォーカス移動、ドロワーの開閉とキーボード操作、横スクロールの不発生、
特大文字時を含むアンカー移動でヘッダーが見出しを隠さないこと、
「ご予約」からの遷移、実在しない電話番号へのリンクが残っていないこと。

加えて、JS無効時に本文が見えること、一部の機能が例外を出しても他が動くこと、
文字サイズ標準・大・特大それぞれでヘッダーが崩れないことを、
iPhone 13 / iPhone SE / Pixel 7 / Galaxy S9+ のプロファイルで確認しています。

なお予約フォームは画面上の動作のみで、送信先はまだありません。
