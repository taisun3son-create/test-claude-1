# かんたんホームページビルダー

お店や会社のホームページを、ブラウザ上でかんたんに制作・修正・管理できるツールです。

## 主な機能

- **サイト管理ダッシュボード** — 複数のサイトを作成・複製・削除して一覧で管理
- **テンプレート** — お店向け／会社向け／サロン・教室向けの3種類から選択
- **セクション編集** — メインビジュアル・紹介文・サービス一覧・お知らせ・連絡先をフォームで編集（並べ替えも可能）
- **カラーテーマ** — 5種類のテーマカラーをワンクリックで切り替え
- **ライブプレビュー** — PC／スマホ表示を切り替えながらリアルタイムで確認
- **HTML書き出し** — 完成したページを1つの `index.html` としてダウンロード。そのままレンタルサーバー等にアップロードして公開できます

データはブラウザの localStorage に保存されるため、サーバー不要で動作します。

## 使い方

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開き、「＋ 新しいサイトを作る」から始めてください。

## 技術スタック

- [Vite](https://vite.dev/) + [React](https://react.dev/) + TypeScript
- ビルド: `npm run build`（`dist/` に出力）
