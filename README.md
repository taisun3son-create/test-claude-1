# AIホームページビルダー

お店や会社のホームページを、AIとのチャットでかんたんに制作・修正・管理できるツールです。

専門知識がなくても「工具店向けのホームページを作って」「青色にして」のように言葉で指示するだけでホームページを作成できます。

## 主な機能

### AIホームページ自動生成
「工具店向けの、青色を基調にした信頼感のあるホームページを作って」のように指示すると、業種に合わせたデザイン・キャッチコピー・文章・ページ構成を自動生成します。

対応業種：工具店／飲食店／美容室／整体院／会社（その他は汎用テンプレート）

### AIチャット修正
編集画面のチャットで指示すると即座に修正されます。

- 「青色を基調に信頼感のあるデザインにして」「高級感のある感じにして」
- 「文字を大きくして」「文字を小さくして」
- 「タイトルを「田中工具店」にして」「キャッチコピーを変えて」
- 「メニューを追加して」「地図を表示して」
- 「電話ボタンを消して」

※ 現在は**デモAI**（APIキー不要のルールベースエンジン）で動作します。OpenAI / Claude などの本物のAIに差し替えられる設計です（`src/ai/demoAi.ts` と同じインターフェースで実装）。

### その他の機能
- **電話ボタン** — スマホでワンタップ発信できる「今すぐ電話する」ボタン
- **商品・メニュー管理** — 商品名・説明文・価格・画像を登録
- **画像アップロード** — アップロード時に自動でリサイズ・圧縮
- **Googleマップ連携** — 住所から地図を自動表示
- **直接編集** — フォームでテキスト・画像・セクションの並べ替え・削除
- **ライブプレビュー** — PC／スマホ表示を切り替えながらリアルタイム確認
- **複数サイト管理** — 1つの画面で複数サイトを作成・複製・削除
- **HTML書き出し** — 完成ページを1つの `index.html` としてダウンロード。そのままレンタルサーバー等にアップロードして公開できます

データはブラウザの localStorage に保存されるため、サーバー不要で動作します。

## 使い方

### 開発者向け

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開いてください。

### 配布用ファイルの作成

```bash
npm run build
```

`dist/index.html` が単一ファイルのアプリ本体になります。ダブルクリックでそのまま使えます。

## 技術スタック

- Vite + React + TypeScript
