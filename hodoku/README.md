# 整体院 ほどく（架空のポートフォリオ 3つ目）

神奈川県藤沢市辻堂の、院長ひとりで営む完全予約制の整体院という設定のサイトです。**実在の院ではありません**（院名・院長名・電話番号・お客様の声・数字はすべて架空）。

ココナラで2万円前後のWeb制作を頼む人にいちばん多い「整体院・サロン」に向けた見本です（調べた結果は Obsidian 記憶書「ココナラのお客さん層」「ココナラの予約フォームと売り方」）。
1つ目（家事代行・水色と緑）、2つ目（古民家喫茶・生成りと明朝の縦書き）と重ならないようにしています。

- 色：生成りグレー `#F6F2EC` の土台、墨青 `#2B3640` の文字、青鼠 `#3D5A6C`、差し色は赤土 `#A84E2A`（予約ボタンだけ）
- 文字：見出し Zen Maru Gothic、本文 BIZ UDPGothic（年配の方にも読みやすいUDフォント）、英字と数字 Outfit
- このサイトだけのもの：「からだの結び目を ほどく」から、からまった糸がほどけて1本の線になる飾り（ロゴ・最初の画面・見出しの頭）と、気になる場所に印をつけた「からだの絵」

## ページ（6ページ＋付属）

| ファイル | 中身 |
|---|---|
| index.html | トップ（最初の画面、今日の受付、お悩みの入口、大事にしていること、料金、はじめての日の流れ、お客様の声、院長、受付時間・アクセス、よくある質問、お知らせ） |
| first.html | はじめての方へ（施術の考え方、当日の流れ、服装と持ちもの、院長のこと） |
| symptoms.html | お悩み別（肩こり・腰痛・頭痛・産後・姿勢。見かた・施術・おうちでできること） |
| menu.html | 料金・メニュー（回数券、お支払い、キャンセル） |
| reserve.html | ご予約（WEB・電話・LINEの3つの方法、受付カレンダー、予約フォーム） |
| en.html | 英語のページ |
| privacy.html | プライバシーポリシー（付属ページ。数えない） |
| 404.html | ページが見つからないとき（付属ページ） |

## 予約のしくみ（出品の売りになるところ）

- **受付カレンダー**：今月と来月。定休日（水曜）と、`news.json` に書いた臨時のお休み（`days`）が自動で「休」になる
- **予約フォーム**：メニューを選ぶ、第3希望まで日時を選ぶ（水曜・臨時休は選べない、土日は 9〜16時、平日は 10〜19時の枠だけ出る）、送る前に「送る内容の確認」が出る、エラーは欄のすぐ下に具体的に、ロボット対策つき。`?menu=first` などで来るとメニューが選ばれた状態になる
- 送り先は `reserve.html` の `data-endpoint`（見本なので空＝送ったふり）。実際の案件では Formspree（月50件まで無料）をお客さん名義で
- LINE・予約サービス（Airリザーブなど）を使っているお店は、ボタンを置きかえる

## 作り方・直し方

```bash
python3 tools/images.py   # 写真を作り直すときだけ（_photos/ に元写真が必要。licenses/photos.md 参照）
python3 build.py          # HTML を書き出す。リンク切れがあると止まる
node tests/shots.js       # PC とスマホで全ページを撮影（tests/shots/）
node tests/func.js        # ドロワー・カレンダー・予約フォームなど14項目
node tests/a11y.js        # 320px〜PCで、はみ出し・小さい文字・押しにくいボタン・薄い文字
```

- ヘッダー・フッター・電話番号・受付時間は `build.py` の上のほう1か所
- 本文は `src/page-*.html`。**生成された `*.html` を直接直さない**
- 全ページ noindex（架空の院なので）。`build.py` の `INDEXABLE = True` で外せる
