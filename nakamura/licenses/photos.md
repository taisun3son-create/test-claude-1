# 写真の出どころ（ぱくたそ）

ぱくたそ利用規約（https://www.pakutaso.com/userpolicy.html）の範囲で使用。商用OK・クレジット表記は不要。
元写真は `_photos/` に置いて `python3 tools/images.py` で書き出す（`_photos/` は Git に入れていない）。
施術服の胸に実在の院名が写っている写真は、その部分を切り落として使っている。

| 使っている名前 | 写真ページ |
|---|---|
| table（最初の画面） | https://www.pakutaso.com/20160541147post-7967.html |
| neck（院長） | https://www.pakutaso.com/20160648165post-8131.html |
| shoulder（スタッフ） | https://www.pakutaso.com/20230806240post-48279.html |
| back（施術の手元） | https://www.pakutaso.com/20160437112post-7702.html |
| spine（いまは使っていない） | https://www.pakutaso.com/20160425112post-7696.html |

人が写る写真は「写真はイメージです」と書いている。本当の案件では、院の中と院長・スタッフ本人の写真に差しかえる。
