# 栗の木舎（架空のポートフォリオ 2つ目）

長野県小布施町の、古い味噌蔵を直した喫茶店という設定のサイトです。**実在のお店ではありません**（店名・店主名・電話番号・お知らせはすべて架空）。

1つ目の「陽だまり家事サポート」（やさしい・安心、水色系）とはわざと違う雰囲気にしています。
デザインの手引き（`/mnt/project-files/design/design-guide.md`）の **3-B ナチュラル・和** に沿って作りました。

- 色：生成り `#F3EEE4` の土台、墨 `#2B2420` と栗色 `#6B4630`、差し色は柿色 `#A5432A`（予約ボタンと「お休み」だけ）
- 文字：本文 Zen Kaku Gothic New、見出し Shippori Mincho B1（縦書き）、英字ラベル Cormorant Garamond
- 和らしさ：縦書きの見出し、漢数字の番号（一・二・三）、アーチ形・丸形に切り抜いた写真

| ファイル | 中身 |
|---|---|
| index.html | トップ（大きな写真＋縦書きのコピー、今日の営業、お知らせ、こだわり、品書き、写真の横すべり、営業時間・案内図、よくある質問、予約のさそい） |
| about.html | お店について（店主のあいさつ、珈琲のこと、蔵のあゆみの年表） |
| menu.html | メニュー（4つのタブで切りかえ。税込の料金表） |
| news.html | お知らせ一覧（種類で絞りこめる、開いて読める） |
| reserve.html | ご予約・お問い合わせフォーム |
| en.html | 英語のページ（観光の方向け） |
| privacy.html | プライバシーポリシー（フォームに必要な付属ページ。ページ数には数えない） |
| 404.html | ページが見つからないときの案内（付属ページ。検索には出さない。公開サービスで「404ページ」に設定する） |

## 盛り込んだ機能（オプションの見本）

| 機能 | どこで見られるか |
|---|---|
| スマホ対応 | 全ページ。スマホでは下に「電話する／席を予約する」の帯がずっと出る |
| 下層ページの追加 | トップ＋5ページ（出品プランの「6ページまで」に合わせた。プライバシーポリシーはフォームに必要な付属ページで、数に入れない） |
| 予約・問い合わせフォーム | reserve.html。ご用件で入力欄が切りかわる、定休日はえらべない、入力ミスをその場で知らせる、ロボット対策つき |
| お知らせ（更新できる欄） | トップに新しい3件、news.html に全件。`news.json` に1件書き足して `python3 build.py` するだけで両方が変わる |
| Googleマップ | トップの「営業時間・アクセス」。最初は手描きの案内図を出し、押すとGoogleマップに切りかわる（表示が速い） |
| SNS（Instagram）への誘導 | トップの「蔵の日々」 |
| 写真の横すべり（スライダー） | トップの「蔵の日々」。指でも、← → ボタンでも動く |
| 今日の営業表示 | トップの写真の下の帯。日本時間で「ただいま営業中」「本日は定休日」などに自動で変わる |
| メニューのタブ切りかえ | menu.html |
| よくある質問（開いて読む） | トップ |
| 英語ページ（多言語） | en.html、ヘッダーの「English」（出品プランの「英語・多言語」の見本） |
| 動き（じんわり・スルッ） | トップの写真がゆっくり引いて文字が順番に出る、スクロールでじんわり表示、ナビの下線が伸びる、ボタンが押すと沈む、スマホのメニューが右から出入りする、質問の開け閉めがなめらか。本「CSSとJavaScriptで作る 動くUIアイデアレシピ」のナチュラル・和向けの動きだけ使い、弾む・回る・光るは使わない。「動きを減らす」設定の人には動かさない |
| 検索・SNS向けの設定 | 各ページのタイトルに「小布施＋古民家喫茶＋店名」、ページごとの説明文、SNSで貼ったときの画像（og.jpg）、ファビコン、お店の情報（構造化データ）、sitemap.xml・robots.txt |

> 架空のお店なので、全ページに「検索に出さない」設定（noindex）を入れています。`build.py` の `INDEXABLE = True` で外せます。

## 作り方・直し方

```bash
python3 tools/images.py   # 写真を作り直すときだけ（_photos/ に元写真が必要。licenses/photos.md 参照）
python3 build.py          # HTML を書き出す。リンク切れがあると止まる
```

- ヘッダー・フッター・電話番号・営業時間は `build.py` の上のほう1か所
- 本文は `src/page-*.html`。**生成された `*.html` を直接直さない**（次のビルドで消える）
- 写真は `{{img:名前|説明}}`、アイコンは `{{icon:名前}}` と書くと、ビルドで置きかわる

## 検査

```bash
node tests/shots.js   # パソコン(1440px)とスマホ(iPhone 13)で全ページを撮影。横はみ出し・画像切れ・JSのエラーを確認
node tests/func.js    # ドロワー・タブ・絞りこみ・フォーム・地図ボタン・JSなしでも読めるか（16項目）
node tests/a11y.js    # 320px・375px・1440pxで、はみ出し・13px未満の文字・44px未満のボタン・薄い文字色がないか
```

（Playwright が必要。クラウドの環境では `PW=/opt/node22/lib/node_modules/playwright` を前につける）

## フォームを本当に届くようにするには

`src/page-reserve.html` の `data-endpoint=""` に送信先（Formspree など）のURLを入れてビルドし直します。空のままだと、完了画面が出るだけでどこにも届きません。
